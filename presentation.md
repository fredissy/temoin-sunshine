# Welcome to Sunshine !

## Introduction

### What is its purpose ?

Sunshine is a powerful tool to compare different branches of the same project, in order to make sure some important commits (**references**, in Sunshine vocabulary) on a given branch are corectly reported (**reports**) on other branches.

It gives you great overview of *what* is reported *where*, and when it was reported, and with which version of your software project.

Sunshine is designed to be agnostic regarding kinds software configuration management. For now, it just handles GIT, but good wills are welcome to implement other SCM types.

### Why ?

I started working on this project because I searched for such tool for a professionnal requirement, never found anything, and ended up updating an Excel sheet with my colleagues.
